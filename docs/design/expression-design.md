# Agent Indicator 动态表情设计规范

当前正式方案为 **motion-eyes-v5**。用户确认以 [六状态动态预览](video-motion-review-v5.html) 的最新版本替代此前柔软伙伴实现。柔软伙伴及三套静态候选保留为历史参考，不再作为固件实现基准。

## 视觉语言

320×240 横屏，黑色背景 `#08090e`，银灰胶囊眼 `#b8bdc4`。联网六态不使用嘴巴、腮红、眉毛或瞳孔；离线状态使用心电图形嘴巴。以双眼整组位移、眼形变化、停顿表达状态；辅助标记仅用于思考、书写和等待。眼睛基准中心为 `(116.3,103)`、`(203.7,103)`，宽约 29.6 px，高约 67.1 px。等待使用琥珀色 `#e89820`，异常使用深红 `#b51f32`。

默认表情页只保留底部连接点；点击进入原有文字调试页。离线采用插头眼、插座眼与心电图嘴巴，详见下文。动画本地运行，上限约 30 fps，保留 PSRAM 帧缓冲、8-bit 回退和文字页降级。

## 六种状态

| 状态 | 动态规则 |
| --- | --- |
| 空闲 idle | 大部分时间静止，偶尔侧看 8 px 后回正；观察周期约 7.2 秒，自然眨眼。 |
| 思考 thinking | 右上看并停顿，回正，再左上看并停顿；周期 8 秒，两侧各停约 1.8 秒。横向视线幅度 23 px，向上最多 22 px；高矮眼形随方向交换（约 78/46.8 px），停顿中加入一次小幅回看。两个小点在左侧必须水平镜像，越向外越高，不能仅平移。 |
| 执行 running | 每轮约 5.27 秒。笔从左到右只写一行，书写约 1.67 秒，眼睛与笔尖使用同一笔迹路径，横向从约 −24.7 px 到 +24.7 px，并随笔画小幅上下移动；笔放大 15%。写完抬笔并清除整行；眼睛看向左上或右上，轮次间交替方向，随后回正；笔回到原起点写新一行，不累积多行。 |
| 等待 waiting | 琥珀色眼睛睁大，左右张望约 16 px，各停留约 1 秒，再回正；周期 4.8 秒。底部单点以 3.6 秒周期缓慢明暗变化，与空闲明显区分。 |
| 完成 done | 笑眼进入时轻抬约 600 ms，在约 0.85–1.13 秒间仅左眼闭合再张开，右眼保持笑眼。随后双眼持续保持笑眼，不重复庆祝，也不按时间切换为 idle。 |
| 异常 error | 深红 xx 眼睛，进入时轻摇一次，约 550 ms、幅度不超过 4 px；随后保持，不反复摇晃或闪烁。 |

普通眨眼约每 5.7 秒一次，闭合张开约 180 ms；done 使用单独的一次左眼眨眼，error 不叠加眨眼。状态切换用约 200–350 ms 的缓动与淡入淡出。笔画用短折线表达书写，不显示真实任务内容，也不代表完成百分比。

## 与事件协议的关系

本次将显示语言收敛为六态，不删除或改写既有 `agent.event` 协议。

| 原始状态 | 表情 |
| --- | --- |
| idle、sleepy、sleep | 空闲 |
| thinking、searching、speaking | 思考 |
| running、editing、tool | 执行 |
| waiting、done、error | 同名表情 |

调试页仍显示真实原始状态，别名映射只作用于表情。同一显示状态内事件更新不重置动画周期。done 保持到收到其他显示状态；CLI Stop 表示响应结束，不保证任务成功。未收到的状态不能由动画推测产生。

## 实现和验收

固件：`firmware/stackchan/include/face_renderer.h`，启动标识 `face design=motion-eyes-v5`。网页预览为几何和节奏参考，ESP32 用本地图形绘制；整数像素栅格化与帧耗时可能造成轻微差别。

重点检查：左上小点方向、单行清除、视线跟笔移动、写完抬眼回正、等待张望、完成只有左眼眨一下且持续保持、点击切页及网络恢复。更换固件和维护 bridge 的窗口需标注在长期采样记录中，不算连续稳定运行。


## 离线与 v5 构图

用户已确认 v5，替代 v4 为正式实现基准。联网眼睛在 v4 基础上宽高再放大 20%，中心间距不变。思考气泡向外 34 px、向上 15 px，右侧点为 (266,37)、(277,27)，左侧水平镜像为 (54,37)、(43,27)。

离线不属于 Agent 六态，由连接状态覆盖显示：中性灰色 #808080，左眼为圆润双脚插头，右眼为带插孔的胶囊插座，保持双眼轮廓。眼睛为 29×58 px，左上角分别为 (102,78)、(189,78)，不张望、不眨眼。心电图嘴巴位于 x=120–200、y=163–184；光点每 3.2 秒沿折线扫描一次，同时缓慢呼吸。它是连接状态的视觉隐喻，不代表真实生理数据。重连后恢复真实 Agent 状态；不沿用旧版下方插头插座图标或半闭眼造型。
