# Agent Indicator 威朗普表情设计规范

当前正式方案为 **willump-led-v3**，以 [七态动态预览](willump-face-preview.html) 的 study 03 为造型基准。固件版本为 `2026.10.15-r1`，2026-10-15 已烧录，并通过 371 条设备逻辑断言；见 [本轮验收](../offline-validation-2026-10-15.md)。银色 v5 已成为历史方案。

## 视觉语言

320×240 横屏，以「合金巨兽 努努和威朗普」的电子屏脸为参考。图片由用户提供：thinking1.png、thinking2.png、execute.png、waiting.png、error.png；离线采用用户在 2026-10-15 确认的[叉眼笑脸示意图](offline-cross-eyes-preview.png)，替代容易误解为低电量的电池造型。空闲和完成沿用上一版威朗普预览中的笑脸。

深蓝背景 `#060e18`，青蓝主体 `#49d9ff`。点阵间距 4 px，亮芯 3×3 px，外层 5×5 px 使用主体色与背景混合 18% 的暗光。屏幕不绘制装甲边框。表情页底部保留连接点，点击屏幕切换到原有文字调试页。

动画在设备本地运行，上限约 30 fps；保留 PSRAM 帧缓冲、8-bit 回退和文字页降级。网页为几何与时序参考，整数栅格化、浮点舍入和实际帧耗时可能造成细微差异，实屏观感仍需人工确认。

## 七种表现

以下坐标除特别注明外均为点阵坐标，换算屏幕像素时乘 4。

| 状态 | 造型与动画 |
| --- | --- |
| idle | 保留浅弧眼与方块宽笑嘴。眼中心 x=28/52、基线 y=24；视线偶尔侧看 8 px 后回正，周期 7.2 秒。自然眨眼周期 5.7 秒、闭合张开约 180 ms。 |
| thinking | 对应 thinking1 / thinking2，短横眼位于 (24,21)/(51,21)，尺寸 5×2。矩形嘴 x=21–58、中心 y=36；嘴高在 13 格与 4 格之间缓动，边框厚 2 格，收合时成为实心横条。周期 2.4 秒：张嘴保持至 0.55 秒，0.55–0.9 秒收合，保持至 1.5 秒，1.5–1.85 秒张开，保持至周期结束。 |
| running | 整张屏幕显示双板击球，无眼睛和嘴巴。两板 x=16/62、尺寸 2×12 格，上下移动；小球为五格十字组成的圆形光点。球心的屏幕坐标 x=76–240、y=52–188；每 1.4 秒触板一次，触板后水平反向，纵向到边界后反射。两板在各自碰撞时到达球的实际高度。 |
| waiting | 对应 waiting.png：青蓝 8×8 格方眼，x=24/48、中心 y=25；平嘴 (29,41)、尺寸 22×2。保持正视，眨眼周期 6.8 秒、闭合中心 6.29 秒。 |
| done | 保留招牌宽笑嘴与较高笑眼。入场轻抬约 600 ms，0.85–1.13 秒间仅左眼闭合再张开，然后保持笑脸直到新事件或断线。重复完成不重播。 |
| error | 对应 error.png：背景 `#230913`，向内尖括号眼 `#ff775c`，短横嘴 `#ffa174`。两眼由 (23,21)→(28,26)→(23,31) 与 (55,21)→(50,26)→(55,31) 构成，厚 2 格；嘴 (35,41)、尺寸 10×2。仅入场轻摇约 550 ms，然后保持，不持续闪烁。 |
| offline | 青蓝叉眼与弧形笑嘴，固定显示，不眨眼或呼吸。两眼以 x=28/52 为中心，分别由 (center−4,19)→(center+4,27) 和 (center+4,19)→(center−4,27) 两条厚 2 格的对角线组成；嘴为 (26,37)→(29,40)→(34,42)→(40,43)→(46,42)→(51,40)→(54,37) 的厚 2 格折线。颜色与正常状态同为 `#49d9ff`，底部保留暗色连接点。 |

击球动画仅表示执行中，不代表任务进度，也不启用设备游戏控制。正常状态切换重新绘制对应造型；空闲、完成的眼组位移采用指数平滑，系数 `1-exp(-dt*12)`。同一显示状态内普通事件更新不重置动画周期；新的实时完成 ID 可重启庆祝。

## 事件与头部策略

既有 `agent.event` 协议和事件映射保持不变：

| 原始状态 | 表情 |
| --- | --- |
| idle、sleepy、sleep | idle |
| thinking、searching、speaking | thinking |
| running、editing、tool | running |
| waiting、done、error | 同名表情 |
| 连接断开或未收到合法 hello | offline |

所有 Agent 状态保持到下一条事件，不因静默自动变为空闲。调试页与表情页使用同一接受事件。最近 32 个完成 ID 去重；重连旧完成快照仍展示 done，但不重播已有庆祝。新旧快照依据 bridge 的 hello.at 与 event.at 比较，不使用设备 UTC 推断。

头部仍只控制 ID 2：空闲或断线回水平，工作抬头约 20°，等待、完成和异常保持已有目标。保留本机 level=591、target=655、350 ms 稳定门槛、900 ms 移动，以及故障重试和限位；表情代码不修改舵机校准或联网配置。

## 源码与验收

- `firmware/stackchan/include/face_motion.h`：调色板、嘴部开合、击球/竖板轨迹、眨眼与入场动作。
- `firmware/stackchan/include/face_renderer.h`：点阵绘制与帧缓冲，启动标识 `face design=willump-led-v3`。
- `firmware/stackchan/src/logic_tests.cpp`：碰撞反向、40 次触板、2000 帧运动边界、嘴部关键帧、完成保持、协议解析和头部策略。

2026-10-15 串口确认版本、帧缓冲初始化和校准保留；Wi-Fi 仍报告重试，因此联网六态与实屏像素观感尚待验收。烧录和自动逻辑测试不能代替目视确认，详见本轮验收记录。
