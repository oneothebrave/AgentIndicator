# StackChan 头部姿态

仅控制 ID 2 俯仰舵机，UART1 1Mbps、TX6/RX7，PY32 IO0 供电。使用官方 StackChan-BSP 的最小驱动子集，保留来源和许可证。水平旋转 ID1 不发命令，原厂 servo/zero_pos_2 只读。

首次需人工确认水平姿态，以反馈位置作为水平基准，存储于独立 NVS indicator-head；不会自动把任意启动位置当成水平。方向小幅试验通过后启用自动状态控制。

- 空闲、睡眠别名、离线：水平。
- 思考、执行及对应别名：抬高 10°，32 原始位置单位。
- 等待、完成、异常：保持当前目标。
- 状态稳定 350ms 后发一次 900ms 定时位置命令；重复事件不重复驱动。

串口调试字符：h 保存已人工确认的当前水平基准；u 抬高 5°；n 回水平；e 启用并保存自动控制；x 停止自动控制、关闭俯仰扭矩并保存禁用。无校准时不运动。读取失败不运动，人工确认的水平基准须在原厂零点 ±5°内；运动目标严格限制在该基准至抬头 10°之间，且原始位置必须在 0–1000。水平基准需实机确认，不对舵机原厂零点重标定。

官方参考：https://docs.m5stack.com/en/arduino/stackchan/servo ，https://github.com/m5stack/StackChan-BSP 。官方推荐运动角度 5–85°；是否能在机械水平位置使用零度必须在校准中确认，不盲目执行 goHome。

水平校准：用户确认当前水平正对前方，反馈 raw=591、原厂 zero=599；保存独立基准 591，不改写原厂校准。已发送 5°测试（607）并回水平（591），回程前反馈 605。方向及实际回平等待用户确认，自动模式暂未启用。

用户确认 5°抬头与回平正常，无异常。随后启用并持久化自动控制，串口确认 automatic-enabled rise=10deg，工作目标 raw=623、水平 raw=591，动作时长 900ms。

工作抬头调整为 20°：相对水平基准增加 64 原始位置单位，本机工作目标为 655。运动范围限制同步为水平至 +20°，动作时长保持 900ms，小幅调试命令 u 仍为 +5°。此记录替代上方 10°工作角度。
