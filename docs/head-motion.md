# StackChan 头部姿态

当前固件 `2026.09.08-r1`：空闲水平、工作抬头 **20°**。本机人工确认的水平基准为 raw=591，工作目标为 raw=655；原厂 zero=599 只读。以前的 10°方案已被替代。

仅控制 ID 2 俯仰舵机：UART1、1Mbps、TX6/RX7，PY32 IO0 供电。使用官方 StackChan-BSP 的最小驱动子集，保留来源和许可证。不向 ID 1 或广播地址发送运动命令，不改写原厂校准。

| 状态 | 目标 |
| --- | --- |
| idle、sleepy、sleep、离线 | 人工确认的水平位置 |
| thinking、running、editing、tool、searching、speaking | 水平 +64 原始单位，约 20° |
| waiting、done、error | 保持已有目标；启动后尚无目标时用水平 |

目标稳定 350ms 后，发送 900ms 定时移动命令。已到目标且扭矩启用时，重复状态不重复发命令。扭矩停用后重新启用，即使目标没变也会重新发送位置并恢复扭矩。

位置必须在 0–1000，水平校准必须在原厂零点 ±16 原始单位内，运动范围限制在水平至水平+64。无有效校准时不自动运动。通信应答或舵机状态异常会记录失败，至少间隔 1 秒再试，最多 3 次；随后保持故障锁定，须显式 `e` 或手动调试命令恢复。故障不根据显示状态变化无限重试。

串口命令（115200）：

| 字符 | 行为 |
| --- | --- |
| `v` | 读取固件版本、水平、目标、位置反馈、自动模式与故障标记 |
| `h` | 保存已人工确认的当前水平位置，关闭自动模式 |
| `u` | 临时手动抬头 5°，关闭本次运行的自动模式 |
| `n` | 临时手动回水平，关闭本次运行的自动模式 |
| `e` | 恢复自动模式与重试能力，并保存启用配置 |
| `x` | 停止自动模式、关闭俯仰扭矩并保存禁用配置 |

设置保存在独立 NVS `indicator-head`。常规烧录不擦除该分区。新设备必须重新人工校准；不能复用本机 591 或把任意开机位置当作水平。

2026-09-09 验证：ESP32 逻辑测试覆盖稳定门槛、20°限位、状态保持、离线回平、重启用、重试与时钟回绕。正式固件串口确认 `x→e` 在同一水平目标恢复扭矩并重新发出 target=591；真实 CLI 工作时 target=655、反馈 raw=653、fault=0。反馈与目标有少量差异，不表示角度经过外部测量。
